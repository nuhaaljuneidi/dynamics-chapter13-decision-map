# Chapter 13: Motion of a Point Decision Map

An interactive decision map for selecting a solution method for particle-kinematics problems from Bedford and Fowler's *Engineering Mechanics: Dynamics*, Chapter 13.

Developed by **Dr. Nuha Aljuneidi** for engineering education and independent study.

## Live resource

[Open the Chapter 13 decision map](https://nuhaaljuneidi.github.io/dynamics-chapter13-decision-map/)

## Learning purpose

The map starts from the kind of motion information a problem gives (straight-line, curvilinear, or relative motion) and leads students to the right coordinate system and kinematic relations, including relative motion of two points (§13.8).

Students can download a personalized copy of the map, with their name and course section, as an image.

## Use locally

Open `index.html` in a modern browser. The tool uses plain HTML, CSS, and JavaScript and requires no build process.
