What kind of motion information is involved?
Relative Motion — §13.8
Two or more points
rA = rB + rA/B
vA = vB + vA/B
aA = aB + aA/B
Details
All absolute quantities are measured relative to the same reference frame.
Use this relation together with the coordinate representation appropriate for each point's motion.
Angular Motion of a Line — §13.5
ω = dθ/dt
α = dω/dt = d²θ/dt²
α = ω dω/dθ
Details
These relationships have the same mathematical form as the relationships for straight-line motion.
ω and α are also used in polar/cylindrical motion, but Angular Motion is an independent section.

Which description best matches the information supplied?
Position s(t) given — §13.2
Method: differentiate.
v = ds/dt
a = dv/dt = d²s/dt²
Velocity v(t) given — §13.2
Differentiate for a; integrate for s.
a = dv/dt
Details
s − s₀ = ∫t₀t v(τ) dτ
Acceleration a(t) given — §13.2
Integrate with respect to time.
v − v₀ = ∫t₀t a(τ) dτ
Details
s − s₀ = ∫t₀t v(τ) dτ
Constant Acceleration — §13.2
v = v₀ + a₀(t − t₀)
s = s₀+v₀(t−t₀)+½a₀(t−t₀)²
v² = v₀² + 2a₀(s − s₀)
Use only when acceleration is constant.
Acceleration a(v) given — §13.3
Route 1 — velocity vs. time:
dt = dv / a(v)
Details
t − t₀ = ∫v₀v du / a(u)
Route 2 — velocity vs. position:
a = v(dv/ds)
ds = [v / a(v)] dv
s − s₀ = ∫v₀v [u / a(u)] du
Acceleration a(s) given — §13.3
a = v(dv/ds)
Details
v dv = a(s) ds
½(v² − v₀²) = ∫s₀s a(ξ) dξ
Graph or Piecewise Data — introduced in §13.2
Another way the motion information may be supplied; use slopes, areas, or interval-by-interval integration.
slope of s–t graph = v
slope of v–t graph = a
Details
area under v–t graph = Δs
area under a–t graph = Δv
For piecewise equations, carry the ending position and velocity of one interval into the next interval as its initial conditions.
↗ Also applies componentwise in curvilinear motion.
Cartesian Coordinates — §13.4
r = xi + yj + zk
v = ẋi + ẏj + żk
Details
a = ẍi + ÿj + z̈k
Useful when coordinates, component functions, or a Cartesian path equation are supplied. Cartesian coordinates can describe any path.
Projectile motion (neglect drag, +y upward):
a_x = 0   a_y = −g   a_z = 0
Horizontal and vertical motion use the same time.
Normal and Tangential Components — §13.6
v = v et
a = (dv/dt)et + (v²/ρ)en
Details
a_t = dv/dt — change in speed
a_n = v²/ρ — change in direction
en points toward the concave side of the path. Useful when path curvature and speed are known or needed.
Polar and Cylindrical Coordinates — §13.7
r = r er
v = ṙer + rθ̇eθ
a = (r̈−rθ̇²)er + (rθ̈+2ṙθ̇)eθ
Details
−rθ̇² = centripetal term.  2ṙθ̇ = Coriolis term.
Cylindrical extension:
r = r er + z ez
v = ṙer + rθ̇eθ + żez
a = (r̈−rθ̇²)er + (rθ̈+2ṙθ̇)eθ + z̈ez
Useful when position or constraints are naturally expressed using radial distance r and angle θ — circular, orbital, and central-force motion.
Choose the representation from the information supplied — not from path shape alone.
• Cartesian coordinates can represent any path.
• Normal–tangential components emphasize speed and curvature.
• Polar/cylindrical coordinates emphasize radial and angular quantities.
